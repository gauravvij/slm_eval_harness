Benchmarking Methodology

Our evaluation framework uses a Local-First approach. All models are executed as GGUF binaries via llama-cpp-python on a dedicated 32-core AMD EPYC node. This eliminates network variability and provides a realistic view of SLM performance on commodity hardware.

How to Read Metrics

  • TTFT (Time to First Token) Measures responsiveness. Lower is better for chat/interactive apps.
  • Throughput (tok/s) Measures raw generation speed. Higher is better for batch processing.
  • Pareto Frontier The ideal balance between RAM usage and Accuracy. Models closer to the top-left of the scatter plot are most efficient.
